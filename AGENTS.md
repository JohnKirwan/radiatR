# radiatR: notes for AI agents

Read the agent guide before analysing data with this package. It is the single
source for angle conventions, calibration, failure behaviour and pitfalls.

- In R: `vignette("agent-guide", package = "radiatR")`
- Online: <https://johnkirwan.github.io/radiatR/articles/agent-guide.html>

To drive radiatR through tools instead of writing R, see `?radiatR_tools` and
the "Driving radiatR through tools" section of the guide.
