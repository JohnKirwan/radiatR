# List registered loader dialects

List registered loader dialects

## Usage

``` r
list_loader_dialects()
```

## Value

A sorted character vector of registered dialect names.

## Examples

``` r
# Built-in dialects plus any registered this session
list_loader_dialects()
#> [1] "anymaze"          "deeplabcut"       "ethovision"       "idtrackerai_wide"
#> [5] "sleap"            "toxtrac"          "trackmate"        "trex"            
```
